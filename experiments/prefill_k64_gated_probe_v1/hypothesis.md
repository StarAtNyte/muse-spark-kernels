# Prefill gated K64 intermediate probe

The prior H200 probe validated one ungated WGMMA tile using K64-permuted weights and activations. This driver extends that to all 64 gated tiles: it permutes gate and up output rows identically so the produced intermediate is in the K64 order expected by phase B, and permutes the K dimension of both weights and input. It compares the unpermuted and reordered gated outputs to a dequantized full matmul + SiLU reference, and compares the candidate with the permuted baseline. It invokes the actual nonpersistent `moe_gemm` gated WGMMA implementation, not the scored persistent fused kernel. It covers one seed, one token tile and normal scales; it is not a full layer, graph replay, special-scale, race or performance test.
