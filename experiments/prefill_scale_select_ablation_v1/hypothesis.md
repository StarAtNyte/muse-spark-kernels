# Prefill repeated-scale selection ablation

Potential K64 permutation would allow a lane to reuse its original scale block across four k16 steps. This screen substitutes `scale_pair_sel(t < 2 ? sc.x : sc.y, t & 1, m16)` for the four existing selection sites without permuting weights or activations. Outputs are intentionally invalid. It is an instruction-scheduling probe, not a valid kernel, correctness test, speedup claim or strict upper bound: the compiler can hoist or duplicate the dynamic selection, and a real permutation would add packing, activation shuffle, altered intermediate publication and possible register pressure.
