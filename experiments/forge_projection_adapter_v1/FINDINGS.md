# Projection O32 adapter screen

The Forge adapter was screened on Modal H200 against the challenge reference for two seeds, using the then-current working projection source (SHA-256 `c96306c10476184f818b3b98f3aadd5b768ff355a5ce2d479c8a09ceaab357d9`). Both passed and were bit-identical in the screen. A separate screen checked invalidation after an ordinary in-place weight version change and replacement. See `probe.log` and `invalidation.log` for the full results.

The Forge task was subsequently pinned to the highest published projection source (SHA-256 `d12bdc54efaa1c8eca185c723a97188ba7e303d67a1671597a3a722500ba7de9`, 1.5395×). The two source files differ by two lines outside the O32 route; the pinned source has not yet been independently calibrated in Forge. This is an adapter correctness screen, not a leaderboard score or a full challenge test. The cache retains weight state and tensor-version handling for inference tensors is unverified. Generic Forge timing does not yet reproduce the official preparation lifecycle.
