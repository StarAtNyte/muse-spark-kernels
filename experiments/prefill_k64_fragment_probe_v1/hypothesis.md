# Prefill K64 real WGMMA fragment probe

Builds the current `moe_gemm` extension and an alternate version with lane-specific scale selection in its nonpersistent consumer. Repackages one 128-row expert with the proposed per-64-element K permutation, permutes its 32 BF16 input rows identically and explicitly constructs the existing XOR-swizzled activation layout. Both baseline and candidate run the actual ungated WGMMA kernel and compare their first 128 output columns against dequantized matrix multiplication at 1.5% relative L2. This is a focused fragment and scale-association test, not a full MoE, gated intermediate, fallback scale, multi-seed or performance validation.
